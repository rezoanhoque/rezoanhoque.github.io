# M. R. Hoque — public website

[Visit the website](https://rezoanhoque.github.io/) · [Projects](https://rezoanhoque.github.io/projects/)

This repository contains only the compiled public website, its public CV, browser assets and bibliographic metadata. The complete Astro source and history, API implementation, private papers, unpublished research and credentials are maintained separately in private repositories. Browser-delivered files are necessarily public.

## Project overviews and selected examples

- [Finance & Economics Literature Lab](https://github.com/rezoanhoque/finance-economics-literature-lab-showcase): overview, evidence workflow and synthetic teaching template.
- [Disclosure Gap Calculator](https://github.com/rezoanhoque/disclosure-gap-calculator-showcase): overview and a small reproducible calculation example.

The literature catalog and worked example are available; the live synthesis backend still requires separate hosting configuration. This static repository does not run an API or contain credentials.

Publishing: GitHub Pages serves the main branch root with Jekyll disabled. Update from a reviewed static build, never by copying the private source checkout or its Git history.
