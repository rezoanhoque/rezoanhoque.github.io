# rezoanhoque.github.io source

Astro + TypeScript source for M. R. Hoque's website.

- Content lives in `src/data/*.ts` (papers, experience, presentations, projects, gallery, tutorials).
- `npm run build` writes the static site to `dist/`.
- `main` holds the built site (GitHub Pages); this `source` branch holds the code.
- The same `dist/` folder, zipped, is uploaded to Hostinger (`public_html`).
